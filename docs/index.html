Trois faces, un cerveau

Le Desktop exécute les téléchargements. L’extension et Premiere observent et pilotent — sans quitter le flux de travail.

Desktop

La Cour

Fenêtre Darkchylde, file FIFO, batch d’URLs, cookies, tray et démarrage Windows. yt-dlp + FFmpeg à la maison.

Extension

Depuis la page

Formats, son, trim, cookies Netscape même navigateur ouvert. Badge de progression, file brouillon si le Desktop dort.

Premiere

LiMBO-premiere

Suivi live, auto-import, bin LiMBo, nouvelles pistes — crée la séquence si elle n’existe pas encore.

Sortie propre

Un dossier par média, un nom daté et typé — plus d’écrasement silencieux. 

{Plateforme} {titre} [{id}]/
  {titre}_{YYYYMMDD-HHMMSS}_{combo|son|video}.ext

Mise en route

  1. Desktop — installeur ou portable (yt-dlp + ffmpeg inclus), puis dossier de sortie au premier lancement.
  2. Extension — charger le dossier dézippé dans chrome://extensions (mode développeur).
  3. Premiere — copier LiMBO-premiere dans %APPDATA%\Adobe\CEP\extensions\, activer PlayerDebugMode, redémarrer.

Windows 11 · Node.js ≥ 20 recommandé (YouTube) · Premiere Pro 14+ optionnel.
