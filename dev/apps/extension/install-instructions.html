LIMBO DESKTOP

Activer l'extension dans votre navigateur

L'extension permet de capturer les formats et de lancer vos téléchargements directement depuis une page vidéo.

Connexion au bureau LiMBo (ws://127.0.0.1:4567)...
🌐 Chrome / Edge / Brave
Chromium MV3

Compatible Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi.

.../extension/chromium
  • 1
    Ouvrez chrome://extensions (ou edge://extensions, brave://extensions) dans la barre d'adresse.
  • 2
    Activez l'interrupteur Mode développeur situé en haut à droite.
  • 3
    Cliquez sur Charger l'extension non empaquetée et sélectionnez le dossier ci-dessus.
Ouvrir chrome://extensions
🦊 Mozilla Firefox
Firefox MV3

Compatible Mozilla Firefox (éditions standard, ESR, Developer et Nightly).

.../extension/firefox
  • 1
    Ouvrez about:debugging#/runtime/this-firefox dans la barre d'adresse de Firefox.
  • 2
    Cliquez sur le bouton Charger un module temporaire...
  • 3
    Sélectionnez le fichier manifest.json ou LiMBo-firefox.xpi dans le dossier ci-dessus.
Ouvrir about:debugging

💡 Conseils & Dépannage

• L'icône reste grisée ou déconnectée ? Vérifiez que l'application LiMBo Desktop est bien lancée (elle s'exécute dans la zone de notification Windows).

• Épingler l'icône : Cliquez sur l'icône en forme de pièce de puzzle (Extensions) dans la barre d'outils de votre navigateur, puis cliquez sur l'épingle pour garder LiMBo visible.

• Mode batch : Vous pouvez également copier-coller directement une liste d'URLs dans l'application Desktop sans passer par l'extension.
